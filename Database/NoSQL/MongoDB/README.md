# MongoDB Learning Notes + Query Handbook

A simple learning set for understanding MongoDB concepts and practicing the related queries with expected outputs.

## Files

- **`MongoDB ~ Complete Developer's Guide 2026.pdf`** — Use this for MongoDB concepts, explanations, architecture,
 CRUD basics, operators, aggregation, indexes, validation, security, sharding, transactions and other notes.
- **`MongoDB Developer's Query Handbook.html`** — Use this for hands-on query practice. It includes sample data, 
short query meanings, expected outputs and collection state after write operations.

## Recommended Learning Flow

1. **Read the topic from the PDF notes** to understand the concept.
2. **Open the Query Handbook** and practice the queries related to that topic.
3. Compare the shown output and collection state to understand how each query affects the data.
4. Run examples in order wherever the collection state is carried forward.

> **Best way to learn:** Use the **notes for understanding** and the **Query Handbook for practice**. Both are designed to be used together.
