Pre-requisite: (Core Utilities/ Commands)

grep (Globally search for a Regular Expression and Print):
Used to search for and extract specific lines of text that match a targeted pattern or regular expression within files or streams of data.
pgrep (Process Grep):
Used to search the operating systems active process list and return the PIDs of processes that match a specified name or criteria.
netstat (Network Statistics):
Used to display active network connections, routing tables, and interface statistics.
kill:
Used to stop running processes. It requires a Process ID (PID) number.
pkill:
Used to stop running processes based on their name or other attributes.
lsof (List Open Files):
Used to list all files currently opened by running processes.
nohup (No Hang-Up):
Used to run a process in the background that keeps running even after the user logs out or closes the terminal session.
find:
Command used to search for files and directories within a file system based on user-defined criteria (such as name, size, file type, permissions, or modification date).
locate:
Command used to instantly find files and directories by name.
head:
Command used to display the first few lines of one or more text files or streams of data
tail:
Command used to display the last few lines of one or more text files or streams of data
less:
It is a terminal viewer used to browse, search, and scroll through large text files or command outputs one screenful at a time without loading the entire file into memory.
cat:
Utility uses to read data from files and output their content sequentially to the screen.
top (Table of Processes):
An interactive system monitor that provides a real-time, dynamic dashboard of overall CPU and memory utilization with a live list of running processes sorted by resource consumption.
htop:
An advanced, interactive system monitor which works same as top but brings up a vibrant, color-coded, text-graphical interface that supports horizontal and vertical scrolling, full mouse-clicking, etc features. (htop - H is just a name of author "Hisham" who created the tool)
df (Disk Free):
Display a summary of the system's total, used, and available disk space across all mounted file systems.
curl:
The command-line tool used to send network requests.
wget:
Used to download files, assets, or entire web pages directly from the internet using network protocols like HTTP, HTTPS, and FTP
sed:
It's a stream editor that automatically updates, deletes or transforms text line-by-line inside a file or pipeline without opening a visual editor
echo:
Command used to print text, environment variables, or command outputs directly to the screen or redirect them into files
tar:
Command used to bundle multiple files and directories into a single archive file .tar.gz (same command is used to decompress same file as well)
zip:
Command used to compress files and folders directly into a standard .zip archive format to reduce file sizes
unzip:
Command used to extract and restore the files and directory structures contained within a .zip archive
export:
Command used to set environment variables, making them available to any child processes and sub-shells launched from that terminal session
env:
Command used to set environment variables temporarily to a single command only. It will not be available to any child processes and sub-shells launched from that terminal session

1. PROCESS MANAGEMENT

Find Java processes
ps aux | grep java
Find any process running on the system that matches the keyword "java". (ps - Process Status)

Explanation:

The Process Snapshot (ps) command generates a comprehensive snapshot of all active processes. a: Shows processes for all users, not just your current terminal session. u: Displays detailed information including user ownership, CPU, and memory metrics. x: Includes background processes that aren't tied to a specific terminal control screen.

jps
List Java processes with PIDs. It only lists Java processes, no scan like entire OS. (JPS - Java Virtual Machine Process Status Tool).
Kill running process
kill -9 <PID>
Forcefully and instantly terminate (kill) a running process on your computer or server.
kill -15 <PID>
Graceful Shutdown process of given running process PID
pkill -f "spring-boot"
Kill by name pattern. Instantly find and terminate (kill) any running background processes with given name
pgrep -fa "spring-boot"
Prints the matches to your screen safely before destroying them. Always use before, pkill cmd.
Check port usage
netstat -tulpn | grep 8080
Find out which application is using (listening on) network port 8080
lsof -i :8080
Modern Linux command used to find out exactly which application is using network port 8080
Background/foreground jobs
nohup java -jar app.jar &
Run in background (nohup - No Hang-up). & - Shell operator that pushes execution of cmd into the background immediately.
jobs
List all active background tasks/jobs that were started from your current terminal session.
fg %1
Bring background job to foreground for active view (%1 - Job No. 1, %2 - Job No. 2, ...)

4. LOG ANALYSIS

Search logs
grep "ERROR" app.log
Search through a given app.log file & print out every line that contains the word "ERROR".
grep -i "exception" app.log
Case-insensitive search
grep -r "NullPointer" logs/
Recursively scan every single log file inside the logs/ directory to pinpoint exactly where a NullPointerException has occurred. (-r ~ Recursive Search. It scans every single subfolder, sub-subfolder, and nested file)
grep -A 5 "ERROR" app.log
Show 5 lines after match
grep -B 5 "ERROR" app.log
Show 5 lines before match
Count occurrences
grep -c "ERROR" app.log
Return total count of how many errors words occurred in log file
grep "ERROR" app.log | wc -l
Returns exact same result as above cmd, but it does it by chaining two separate Linux utilities together using a pipe. (wc -word count, l - lines)
Filter and pipe
grep "ERROR" app.log | grep "OrderService"
Searches log file to find lines that contain both the word "ERROR" and "OrderService".
tail -f app.log | grep --line-buffered "ERROR"
Used to stream your application logs live while instantly filtering for errors as they happen

7. FILE PERMISSIONS

Change permissions (chmod - Change Mode, chown - Change Owner)
chmod +x script.sh
Grant execute permission. + means add permission
chmod -x script.sh
Remove execute permission. - means remove permission
chmod -rwx script.sh
Remove read, write and execution permission
chmod -r-x script.sh
Remove read and execution permission. Format: rwx (read write execute). Keep - for skipping any one.
chmod +rw script.sh
Grant read and write permission
chmod 755 deploy.sh
Grant rwx-xr-xr permission
chmod 644 config.properties
Grant rw-r--r-- permission
chmod 000 deploy.sh
Completely wipes out permissions for the Owner, the Group, and everyone else

Pre-requisite:

Linux calculates permissions by adding up binary point scores for each individual file: 4 = Read (r), 2 = Write (w) and 1 = Execute (x) So, 3-digit number passed to chmod represents three distinct entities in strict order: [ Owner ] [ Group ] [ Everyone Else ] chmod 755 deploy.sh # This math breaks down into three groups: > Owner (7): 4 (read) + 2 (write) + 1 (execute) = 7 (rwx) The person who created the file can do absolutely everything > Group (5): 4 (read) + 0 (write) + 1 (execute) = 5 (r-x) Team members in the same user group can read and run the script, but cannot edit or accidentally break the code (xr) > Everyone Else (5): 4 (read) + 0 (write) + 1 (execute) = 5 (r-x) Anyone else on the server can also read and execute it

Change ownership
chown user:group app.jar
To transfer the ownership of a file or directory to a specific user and system group
chown -R user:group /opt/app
Transfers the ownership of the /opt/app directory along with every single file, configuration, subfolder and asset hidden inside it to a new user and system group. (-R ~ Recursive Change Owner)
chown user:group /opt/app
Change the ownership of just the top-level /opt/app directory itself...without touching any of the files or folders inside it.

8. TEXT PROCESSING

AWK - extract columns
ps aux | awk '{print $2, $11}'
Print PID and command
cat app.log | awk '/ERROR/ {print $1, $2, $5}'
View given file & pull out three specific pieces of information: the date, timestamp, and error message details, ignoring the rest of the text on the line.

Explanation:

ps aux | awk '{print $2, $11}' ------------------------------- Part 1: ps aux ~ Covered in Process Management Section (Sec. No. 1) Part 2: awk '{print $2, $11}' By default, ps aux prints 11 distinct columns of data. awk is a powerful text-processing utility that treats each column as a variable designated by a dollar sign ($) and its position number. $2: Represents the 2nd column in the data stream, which is the PID (Process ID). $11: Represents the 11th column, which is the COMMAND (the actual program or binary executing). cat app.log | awk '/ERROR/ {print $1, $2, $5}' ---------------------------------------------- Part 1: cat app.log The cat utility reads the entire app.log file from top to bottom and streams the text lines directly into the input of the next command. Part 2: awk '/ERROR/ {print $1, $2, $5}' This is an awk pattern-action block. It handles two tasks simultaneously on the incoming text stream: The Pattern Filter (/ERROR/): The forward slashes define a regular expression search. awk looks at every single line streaming in and instantly drops it unless the line explicitly contains the word "ERROR". The Action Block ({print $1, $2, $5}): For every line that passes the pattern filter, awk tokenizes the line by spaces and outputs only the 1st, 2nd, and 5th chunks of text.

SED - find and replace (sed - Stream Editor)
sed 's/localhost/prod-server/g' config.yml
It searches through the config.yml file, changes every text of localhost to prod-server & previews updated text on screen without modifying the original file.
sed -i 's/8080/9090/g' application.properties
In-place edit. It searches through the application.properties file, changes every port number 8080 to 9090 & permanently saves modifications directly into the file.
Cut - extract fields
echo "user:password:1001" | cut -d: -f1
Extract username (-f1 ~ first field). It splits the text string using the colon (:) as a dividing marker and prints out only the first section, which is user

9. COMPRESSION & ARCHIVES

TAR archives
tar -czf app-backup.tar.gz /opt/app
Create compressed archive. Used to compress the entire /opt/app folder into a single, compact archive file called app-backup.tar.gz. (tar - Tape Archive)
tar -xzf app-backup.tar.gz
Extract archive. Used to Decompress and extract (unpack) all the files out of your backup archive back into your current directory
tar -tzf app-backup.tar.gz
List contents of archive. Used to preview the contents of a compressed archive without actually extracting any files onto your disk

c (Create): Tells the system to build a brand new archive file. z (gzip): Tells the system to compress the archive using gzip algorithm to make the final file size as small as possible. f (File): Specifies that the output should be saved as a specific file on your disk (must always be placed immediately before the backup file name). x (eXtract): The key change here. Instead of packing files together, this tells the system to split the archive open and extract the contents. t (List/Table of Contents): The key modifier here. It tells the system to read the file headers and print out a text list of all the file and directory paths stored inside.

ZIP
zip -r app.zip /opt/app
Compress the entire /opt/app directory and everything inside it into a standard .zip archive named app.zip
unzip app.zip
Extract all the files and folders out of a .zip archive back onto your disk.
unzip -l app.zip
List contents of zip archive. Used to preview the entire contents of a .zip archive without extracting any files

-r : Recursive Compress -l : List content Note: By default, tar just groups files together while zip groups file together and compresses them. -z flag is needed for tar compression.
