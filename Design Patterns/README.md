# Design Patterns - Learning Guide

> **Created by: Dynamic Duo Learners**

This repository is for learning important **Java Design Patterns** in a simple and practical way.

---

## How to Learn Each Design Pattern

For every pattern, follow this order:

### 1. Read the Notes First

Understand:

- What the pattern is
- Why it is needed
- What happens **without the pattern**
- Main idea
- When to use it
- Advantages and disadvantages

Do not start by memorizing code.

---

### 2. Check the Image

Use the image to understand the pattern visually.

Focus on:

- High-level flow
- Class relationship
- Request/object flow
- Before vs after pattern
- Important interview points

The image should help you remember the concept quickly.

---

### 3. Read the Java File

After understanding the notes and image, open the Java example.

Check:

- Interfaces
- Classes
- Object relationships
- Main method flow
- Which class represents which design-pattern role

Then run the Java file and check the output.

---

### 4. Learn the Pattern in This Order

For each pattern:

```text
1. Notes
      ↓
2. Image
      ↓
3. Java Example
      ↓
4. Understand Flow
      ↓
5. Run the Code
      ↓
6. Revise Without Looking
      ↓
7. Practice Interview Explanation
```

---

## Best Interview Preparation Method

For every pattern, try to explain:

```text
What is the problem?
        ↓
What happens without the pattern?
        ↓
What is the solution?
        ↓
How does the pattern work?
        ↓
Real-world example
        ↓
Java implementation
        ↓
Advantages / Disadvantages
```

If you can explain these points without checking the notes, the pattern is prepared.

## Final Revision Order

Use this order before interviews:

```text
1. Read short notes
2. Check image
3. Recall the real-world example
4. Recall WITHOUT PATTERN problems
5. Recall WITH PATTERN solution
6. Check Java classes and flow
7. Explain pattern in your own words
8. Compare it with similar patterns
```

Do not try to memorize every line of code.

Understand:

> **Problem → Pattern → Flow → Java Example**
